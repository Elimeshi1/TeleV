Accessibility Statement

Last updated: October 3, 2026

The website telev.app was designed to conform to Israeli Standard IS 5568 and the Web Content Accessibility Guidelines (WCAG) 2.1, level AA.

Accessibility features

  • Full keyboard navigation and a "skip to main content" link.
  • Semantic structure, defined page language, and text direction.
  • Text alternatives for images.
  • Sufficient color contrast.
  • Responsive layout supporting zoom up to 200%.

The App is fully operable using a TV remote control.

Limitations

Video content displayed in the App is provided by third parties, and the availability of captions depends on the publisher.

support@telev.app. Inquiries will be answered within 14 days.
